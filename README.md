# Mehar's Site

This is my personal portfolio site to share my experience, blogs , achievements and projects on the internet. i sometimes yap here too (alot ig)

Live Link :- https://www.meharfr.xyz/

# Features

- Light and Dark mode toggle
- keyboard navigation for switching between pages/routes
- navbar with page-aware headline and navigation
- Astro js blogs with custom styling using @tailwindcss/typography (prose)
- code snippets in blogs with a copy button generated using js
- responsive design 
- mouse following neko cat
